# AI 智能关务 · Customs Agent

用于开发辅助关务工作的 AI Agent 应用，帮助关务人员处理资料、查询知识和梳理业务流程。

## 计划探索的方向

- 关务知识与政策查询，提供可追溯的来源。
- 单证信息提取、整理与一致性检查。
- 报关要素辅助整理与业务风险提示。
- 通过工具调用协助完成重复性关务工作。

## 当前状态

项目处于初始化阶段，尚未选定技术栈或实现业务功能。

## 开发约定

- API 密钥等配置通过环境变量管理；如需配置模板，使用 `.env.example`。
- 本地业务资料放在 `data/private/` 或 `uploads/`，这些目录已被 Git 忽略。
- Agent 的业务建议应保留依据，关键关务结论由业务人员复核。
