## 正式工作台

运行 `make setup` → `make migrate` → `make seed-demo`（仅本地演示环境，若要复现报告的多版本任务再运行 `make seed-contracts`）→ `make dev`，打开 <http://127.0.0.1:8000/>。未登录自动进入独立的 `/login/`；登录后回到 `/` 或原来的任务与版本。三种主题在登录页与主作业台之间共享，主题偏好只存当前浏览器。不在正式页面展示样例密码，演示账号见[运行手册](docs/开发文档/运行与交接说明.md)。

- **主作业台 `/`**：按角色查看授权队列、筛选任务、核对版本、商品和依据；概览以所选版本的完整商品明细为统计范围。
- **运行与导出 `/workbench/`**：查看版本、阶段和执行记录，获取对应导出。
- **上传与认领 `/uploads/`**：供应商上传或补件，业务员认领；三个入口共享会话，功能受服务端授权约束。
- 查看[本次优化报告](docs/optimization/report.html)与[独立评测口径](docs/optimization/evidence/rubric.md)。

- 登录、权限或网络错误直接显示，不回退样例。两类导出直接返回 XLSX，绑定所选版本和 Run；专家清单还绑定对应提交及可选决定。
- 本地演示采用 mock / inline；以页面标识的实际来源为准。模拟输出不能用于申报，真实输出也须人工复核。
- 正式页面资源采用显式白名单，支持 `DEBUG=False`；API 继续校验会话、CSRF 和任务权限。浏览器验收与生产部署是两个独立环节。
- 原交互原型保留在 `web/workbench.html`，仅在开发模式显式 `?mode=fixture` / `?mode=demo` 访问。设计源文件仍在 `docs/原型/关务预审工作台-v2.html`。
- 验证结果与浏览器阻塞详见 [P08/P20 集成记录](docs/开发文档/验收记录/P08-P20-正式页面集成-20261117.md)。

## 计划探索的方向

- 关务知识与政策查询，提供可追溯的来源。
- 单证信息提取、整理与一致性检查。
- 报关要素辅助整理与业务风险提示。
- 通过工具调用协助完成重复性关务工作。

## 开发约定

- API 密钥等配置通过环境变量管理，需要配置模板时使用 `.env.example`。
- 本地业务资料放在 `data/private/`、`uploads/` 或 `docs/参考模板/`，这些目录已被 Git 忽略。
- 业务对象统一称“审核任务”；技术设计中的“导入批次”（import_batches）只是文件版本的技术载体，归属审核任务。
- Agent 的业务建议应保留依据，关键关务结论由业务人员复核。
