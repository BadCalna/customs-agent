# AI 智能关务 · Customs Agent

用于开发辅助关务工作的 AI Agent 应用，帮助关务人员处理资料、查询知识和梳理业务流程。

## 当前状态

项目进入阶段0：先对齐业务规则与数据口径，再启动功能开发。开发主线依据 [开发任务与阶段交付计划](docs/开发文档/开发任务与阶段交付计划.md)，已确认规则、数据与版本约定、验收用例见 [阶段0文档](docs/开发文档/阶段0/README.md)。

早期 Streamlit 学习原型（Excel 自动入库、历史匹配、属性提取 agent 与三页签预审工作台）已完成全链路验证，代码与运行数据库已于 2026-11-13 清理，不进入仓库；其 [技术方案与数据设计](docs/技术方案与数据设计.md) 和 [SQLite 建表脚本](docs/sqlite_schema.sql) 作为设计参考保留。

真实业务模板放在 `docs/参考模板/`（Git 忽略，仅本地参考），供阶段0 逐格核对；样表副本 `data/private/demo_source.xlsx` 同样仅存本地。

## 计划探索的方向

- 关务知识与政策查询，提供可追溯的来源。
- 单证信息提取、整理与一致性检查。
- 报关要素辅助整理与业务风险提示。
- 通过工具调用协助完成重复性关务工作。

## 开发约定

- API 密钥等配置通过环境变量管理，需要配置模板时使用 `.env.example`。
- 本地业务资料放在 `data/private/`、`uploads/` 或 `docs/参考模板/`，这些目录已被 Git 忽略。
- Agent 的业务建议应保留依据，关键关务结论由业务人员复核。
