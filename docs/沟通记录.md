# AI辅助申报要素与HS归类 · 沟通记录

## 第1轮 · 需求确认（2026-10-29）

### 背景（来自此前多轮业务讨论）

- 业务流程（11步）：ERP拟签 → 采购合同签订 → 货物申报要素制作（关键：HS编码正确性、申报要素完整性合理性）→ 物流文员审核 → 货物到货 → 报关单据制作（关键：重量/件数/品名）→ 报关预录单核对（关键：重量/件数/品名/境内货源地）→ 完成报关 → 大副收据核对 → 提单草本核对（关键：重量/件数/品名/船名/航次）→ 确认提单正本
- 最大痛点："上游乱填、中游没能力核、下游没时间核"，风险集中在物流环节末端；货到后申报时间极度压缩（最后两周高强度加班）
- 初步需求：根据品名+规格+图片获取应填申报要素，辅助填写，区分Excel中的异常数据
- 数据源策略：不采购商业HS数据库，自建知识库（官方公开数据定期更新 + 企业历史申报记录 RAG）；第三方HS库仅作初筛层，须以海关总署"互联网+海关"/单一窗口当期数据核验；疑难归类走海关预裁定（署令236号）
- 载体：业务员端=钉钉H5微应用（拍照+品名规格→AI推荐编码与要素）；物流/审核端=网页工作台（批量导入Excel→异常标注）
- 已验证案例：轴承6224/C3（SKF→8482102000）、热过载继电器LRD12C（施耐德→85364900.90）、固态继电器125A（信息不足，需补电压/品牌/型号——AI应输出缺失字段清单）

### 第2轮 · 口径修正（用户补充）

> 用户原话："我想做双端都做，我想做的是全流程的重构，而不是某个单点的赋能"

**重大口径修正：** 本项目定位为**报关全流程（11步）AI化重构**，不是"申报要素制作"单点赋能：

1. **主线**：ERP拟签→合同→申报要素→审核→到货→报关单据→预录单核对→报关→大副收据→提单草本→提单正本，全链路嵌入AI能力
2. **结构性重构**：
   - 申报准备前移——合同阶段即启动要素预填（打破"货到后两周突击"模式）
   - 核对能力产品化——重量/件数/品名等关键点全部AI自动比对，人工只处理异常
   - 知识库贯穿全流程——每一次成功申报回流沉淀，持续提升推荐准确率
3. AI嵌入点（此前梳理）：步骤3 HS编码推荐（核心）、步骤6 报关单据自动生成（核心）、步骤7 预录单比对（核心）、步骤9 大副收据核对（核心）、步骤10 提单草本核对（核心），及合同、审核、到货、归档等辅助场景
