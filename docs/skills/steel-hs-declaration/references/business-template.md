# 两页签字段映射与回填

适配依据为已学习的象盛镍业—苏州淳鑫业务Excel。以下列号仅用于该模板版本，实际运行按语义表头定位；只分析装箱明细和申报要素，不依赖箱件汇总。

## 装箱明细：商品输入

| 示例列 | 表头 | 用法 |
|---|---|---|
| B / E | 合同号 / 合同项号 | 定位原合同商品，与申报页关联 |
| C / D | 申请单编号 / 物料代码 | 校验关联，保留追溯 |
| F | 合同第一条品名 | 与附件清单品名共同确认商品 |
| G | 附件清单品名 | 补足更具体名称，实质矛盾须保留待确认 |
| H | 规格 | 完整提取尺寸、材料、参数、用途等可用事实 |
| R | 厂家提供型号 | 与H共同形成规格型号；不能替代或覆盖H |
| I / J | 数量 / 单位 | 帮助确认分箱或合并对应，不凭数量决定分类 |
| P / Q | 产地 / 生产商 | 可用业务事实；生产商不等于品牌 |

规格型号保存为两段带来源文本：`规格：{H原值}；厂家型号：{R原值}`。一侧缺失时利用另一侧，不一律判低；关键参数冲突则显式提示。R中疑似HS数字、面密度等与商品身份无关内容，不当作可靠型号。

## 申报要素：匹配、图像与回填

| 示例列 | 表头 | 用法 |
|---|---|---|
| B / C | 采购合同号 / 合同项号 | 与装箱记录定位；合并项号保留成员关系 |
| F | 品名 | 对照装箱明细F/G稽核是否同一商品，保留原名和修改建议 |
| L | 海关编码 | 既有值先核验；在副本填写有依据的完整编号，未定码明确待补 |
| M | 附图 | 真实图片输入；WPS DISPIMG须提取媒体后才能声明识别 |
| Y | 申报要素 | 按查询得到的对应模板回填，已有值也需核查，待填部分红字 |
| 新增或已有列 | 置信度 | 同格写高中低、判断依据、具体待补；低红字，可加浅红底；中黄底 |
| D / Q | 税分类代码 / 退税率 | 保留原值，不将HS复制为税分类代码或凭归类猜退税率 |

N—P、Z—AA等无表头列在样例中有历史问答，不能占用或覆盖。新增列追加在实际已使用列之后。箱号、重量、体积、包装等原字段随工作簿保留，本轮不执行三表核对或推算缺失包装数据。

## 匹配与样例问题

- 用合同号＋项号定位，再用装箱两种品名及规格型号稽核申报品名；名称相似不等于同一商品。
- 同一合同项分装多箱：合并一致属性用于判断，保留全部分配行引用；不同规格/物料时保留子记录。
- 申报合并项号如“24-25”应记录成员24、25。样例“55-27”不能直接改为“55-57”，须列疑似关系待确认。
- 喷涂机规格品牌为德力西，原申报要素写无品牌；需铭牌核实。手电钻H41为1980W、R41含710W，两者都要读取并说明冲突。
- 磨头H32写钨钢、原Y23写合金钢制；需核成分和结构，不因旧申报有字就认定已填完整。
- 仅装箱明细有的减速机不能漏掉；列为待新增申报商品，不匹配到别的同名/近似条目。
- 样例M列的图片数量和合同商品数量不是通用常数；附图可对应合并申报行，须核实具体型号适用范围。

## 输出示例（仅说明格式，不是归类结论）

申报要素：`品牌：按铭牌原值；型号：按已核实型号；用途：待补充（请说明适用设备和具体作用）`。其中“用途”及待补片段红字。

置信度：`低｜依据：规格与厂家型号中的功率矛盾，尚不能确定实际商品身份及归类条件｜待补充：对应型号铭牌、额定功率和实际用途。`。整个置信度格红字，可加浅红底。

## 网页/后端保持相同口径

结果保留商品ID、合同项、两种原品名、联合规格型号、申报匹配关系、图片读取状态、候选及条件、归类理由、要素值/来源/待填状态和具体补数问题。`confidence`为高/中/低；另存`confidence_reason`、`supplement_questions`，Excel展示时合成为同一“置信度”单元格。待填要素与低置信度的红色样式属于导出要求。

AI填写结果标明待人工审核；人工确认值、监管状态与置信度分开。原型仍为此前三页签演示版本，本次仅更新Skill，不代表前端已同步实施两页签逻辑。
