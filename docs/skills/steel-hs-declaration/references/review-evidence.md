# 归类、要素、退税及监管的审核证据

用于预审检索及专家审核解释。此文件定义查证方法，不代表已对本批货物完成联网核验；不预填某年度税率、有效法条或不受控结论。

## 来源分工

| 核查对象 | 优先证据 | 注意事项 |
|---|---|---|
| 中国商品编号、商品描述 | [海关商品编码表](https://online.customs.gov.cn/ociswebserver/pages/cus/#/tgcs/info?paramCode=CusComplex)、[海关总署](https://www.customs.gov.cn/)公开的适用税则及公告 | 编码存在不代表商品符合该编码；记录实际商品条件和适用年度 |
| 归类依据 | 适用税则、归类总规则、类注/章注/子目注释，以及适用的官方归类决定/行政裁定等 | 区分法定规则与说明性参考；匹配适用条件，不凭同名案例认定结论 |
| 申报要素 | [海关商品申报要素表](https://online.customs.gov.cn/ociswebserver/pages/cus/#/tgcs/info?paramCode=CusMerchElement)及当期规范申报要求 | 最长前缀匹配；保留实际字段、顺序、必填性；接口未写年度则版本待核 |
| 出口退税 | [国家税务总局](https://www.chinatax.gov.cn/)、[财政部](https://www.mof.gov.cn/)适用公告、出口退税率文库及相关政策 | 记录退税商品代码、调整文件、生效日期及业务适用条件；关税税率不可代替退税率 |
| 出口许可及其他证件 | 海关当期监管条件、有效目录和发布机关公告 | “出口许可证”原备注不是已经取证；监管条件与两用物项控制分别核查 |
| 两用物项等出口管制 | [商务部出口管制信息](https://exportcontrol.mofcom.gov.cn/)、[中国政府网](https://www.gov.cn/)或相关发布机关的有效法律、条例、清单及公告 | 核实实际技术指标、专门设计属性、目的地、最终用户/用途等；清单HS仅作线索，不代替技术描述和全面审查 |
| 补充线索 | [hsbianma.com](https://www.hsbianma.com/)、企业历史申报及说明书 | 标第三方/历史，核官方适用性；不单独支持高置信度 |

“海关官网的税则书”以官网公开且适用本次日期的原文为准；需财政部/税委会文件时引用原发布机关。不能因为页面能打开或查询日期在当年，就推定文书适用于当年。

常用原文检索对象包括《中华人民共和国进出口税则》及归类总规则、《中华人民共和国海关进出口货物商品归类管理规定》、《中华人民共和国出口管制法》、《中华人民共和国两用物项出口管制条例》、《中华人民共和国两用物项出口管制清单》及后续调整公告。名称是查证入口；执行时仍须取得适用版本、具体条款和与该商品的对应关系，不把本列表当作已完成核查。

## 从问题解释到条款

每项输出形成证据链：**供应商写了什么 → 图片/规格显示什么 → 对应规则要求什么 → 哪项条件满足、冲突或缺失 → 为什么不能确认 → 需提供什么**。

- 例：图是整机，申报要素写零件。先确认本批供货完整性，核适用税目及零件规则，引用实际取得条款；不能先猜条号再给结论。
- 图上额定电压与文本不同，记录双方原值、图片适用型号及来源单元格。未取得本批铭牌时不自动认定哪方错误。
- 退税率不一致：列原率、该待审编码/退税代码、适用日期、官方值及政策出处；条件未明确时两边保留并写待核。图片不包含税率证据。
- 两用线索：列可能条目和技术门槛、已知/未知参数、需核用途/用户/目的地。关键词命中只表示需核，未命中也不是不受控证明；改名不消除真实属性。
- 不适用的法规无需强行引用。查不到正文、条号或年度时说明具体缺口、已尝试来源及对判断的影响，不编造引文，也不将“未查到”写成“无规定”。

## 证据记录与有效性

最小记录：阶段、商品ID/文件版本、发布机关、文书标题、条款或页码、实际打开的URL、适用年度/生效日、查询日、相关原文摘要、与该商品事实的对应关系、查询状态。

- 对候选编码分别记录其成立条件及不同要素模板；未解决前没有唯一可用的最终要素/退税结论。
- 来源冲突时保留双方及日期，优先核原文和有效性，不用第三方覆盖官方。企业历史相同也须核当期规则。
- 系统不填写拟申报日期；核查按查询日进行并标“正式适用日期待核”，不要求补录该字段。官方版本无法确认则相关项待核，不能高置信度。
- 遇到登录、验证码、限流或授权限制不绕过；已授权数据库有可靠版本时可用并记来源。查询失败、资料不足、事实冲突分别标记，不将失败结果判作审核通过。
- 数据初始化及年度/临时公告更新保留旧版本和生效区间；编码拆分、要素/税率/监管条目变化只使受影响结论待复核。此技能不自行建立采集、定时调度或数据库更新任务。
