# 供应商Excel：业务员预审与专家审核

以2026-11-12确认的两阶段流程为准：供应商上传 → 业务员点击预审 → AI独立归类并对比供应商HS → 业务员决定退回、导出补料或提交专家 → 提交后自动触发专家核查 → 专家核查要素、附图、退税及法规 → 专家决定通过（可直接改码）或退回给具体人员。专家通过后的业务动作待补充。

## 阶段与交付

- 先读 [模板字段与输出](references/business-template.md)；需要查证归类、退税及管制依据时读 [审核证据规则](references/review-evidence.md)。本技能仍适用于钢材及其他备品备件，不把所有商品套入钢材参数表。
- 应用传入`stage=precheck`或`stage=expert_review`。用户说“预审”只执行预审；说“专家审核”只执行专家审核并读取该版本预审结果；明确要求全流程才执行两阶段。笼统说“处理Excel”时先做预审并标明专家审核未执行。
- 上传本身只解析文件、留存版本和关联记录；**业务员点击预审**才启动归类查询。专家审核以业务员提交的文件版本为输入，提交后自动触发；两个阶段结果分开保存。
- 只使用装箱明细、申报要素及对应佐证；箱件汇总和其他页签原样保留，不纳入本轮商品审核依据。无必要信息时列明缺口，继续可处理项。
- 保留供应商海关编码、原申报要素、原退税率、图片和历史意见。AI建议写入独立列，禁止覆盖供应商原值或自动变成人工确认值。
- 默认导出保留原模板的审核副本；用户明确要求原位修改时按授权保存。注明阶段、文件版本、分析时间及“AI辅助结果，待人工审核”。本技能不自动退回、发布、报关或写业务数据库。

## 一、确认商品及两个页签的关联

1. 按实际表头语义定位，页签可带“节点①”等前缀。记录数据区、合计、备注、合并单元格、公式及图片；不套固定行列。
2. **主品名**取装箱明细“合同第一条品名”，**别名**取“附件清单品名”。别名用于检索、理解及消歧，不能因更具体而覆盖主品名；双方实质冲突要保留并标注。主品名缺失时标“主品名缺失”，可用别名提出条件候选，但不能伪装成已取得主品名。
3. **规格型号**由“规格”与“厂家提供型号／供应商提供型号”共同组成，分别保留来源和互补参数。用途场景单独保存；本次口述“场景提供型号”暂按此前厂家/供应商提供型号解释。字段不存在就记录缺列，不把“合并申报”“特别注意”等列当型号，不把适配主机型号当商品本体型号。
4. 以文件版本＋合同号＋合同项号关联申报要素页，再用主品名、别名、规格型号、物料代码稽核。不能只凭同名跨合同匹配，也不能把装箱与申报两张表的相同行号直接对应。
5. 分箱重复记录保留全部来源，但不重复归类；合并申报项号解析为明确成员，每个型号分别确认资料适用性。成员疑义、漏申报、多个成员需要不同编码时列异常，不硬填到相似商品行。
6. 读取该申报行真实附图。WPS `DISPIMG`需解析图片ID、关系及媒体；浮图需核实锚点与商品。读不到写“图片未读取”，没有图片写“未提供图片”，不拿公式、文件名或邻行照片当识别结果。
7. 图片只证明可见结构、标识、铭牌文字及其对应型号；不从外观猜成分、工艺、用途、性能、品牌类型或享惠情况。品牌仅取明确资料；生产商不等于品牌。“OK”“已修改”和历史编码都是待核输入。

## 二、业务员预审：独立推荐HS并比较

1. 用**主品名＋别名＋规格＋厂家/供应商型号＋匹配附图**独立查询和归类，先判断商品，再按材质、结构、功能、用途、工艺、参数及归类规则排除分支。供应商HS仅作为后续比较对象，不作为推理正确的前提。
2. 官方商品编码、归类总规则、类注/章注/子目注释及适用归类决定优先；[hsbianma.com](https://www.hsbianma.com/)与企业历史仅补充线索。记录实际使用的来源、适用日期、版本与查询状态；不把第三方标为官方结论。
3. 在申报要素页原“海关编码”**紧右侧**新增或复用`AI推荐HScode`，其紧右侧为`预审结论`。新增列须真实插入并保留被右移字段、图片、公式、合并单元格、历史意见；不能占用原附图或无表头但已有内容的列。
4. 有依据支持唯一中国商品编号时，将完整10位码以文本写入AI推荐列；否则填`待补资料，暂不定码`，条件候选及各自成立条件放预审结论或核查明细，不把多个候选拼成正式编码。
5. 比较供应商HS与AI建议。只规范空格、可识别分隔符及文本表示，保留原文；不补零拼码，不把4/6/8位或13位CIQ当10位相同。结果区分：`一致`、`不一致`、`无法确认`、`供应商未填`、`供应商编码格式/有效性异常`、`匹配异常`。可并列多个异常标签。
6. **即使编码相同，关键资料或当期有效性未证实也标“无法确认”，不能仅凭相同判通过。**不一致也不能断言供应商错误；列明两者、事实、分歧条件及证据。
7. `预审结论`同格写：比较状态、供应商HS、AI建议、归类依据、具体差异/不确定原因、预审置信度（高/中/低）、待补或修改事项、来源及版本状态。详细条款可放核查明细并保留行关联；不能只给“请核实”。
8. 预审不替供应商重填原申报要素或改退税率。可列与归类有关的补料问题；完整要素、退税和监管审核属于下一阶段。预审发现管控线索应保留并提示专家，不因分阶段而隐藏。
9. 业务员查看结果后决定：退回供应商、导出带结论Excel/补料清单让供应商补充，或提交专家。AI只建议，不自动替业务员处置；导出不等于退回或发送。新资料生成新版本，整表重新预审，旧结论留存。

## 三、专家审核：要素、附图、退税及法规

1. 读取业务员提交版本、供应商原HS/要素/退税率、预审建议及匹配附图。先处理HS分歧：明确本次待审编码及理由。无唯一编码时分候选核查并标待确认，不把AI推荐默认为专家定码。
2. 根据待审编码获取当期官方要素模板；前缀模板采用最长匹配，保留字段名称、顺序和必填标识。逐项核对供应商要素与规格型号、主/别名、图片及佐证，输出`匹配`、`缺失`、`冲突`、`证据不足`或`不适用`。
3. 图片重点核对商品形态、供货范围、铭牌品牌、型号、功率/电压等可见事实。图未显示某项≠该项错误；图不足以判断材质、成分、工艺等时需材质证/说明书，不凭图补全。多型号不能默认共用一张图。
4. 可用两页签明确事实生成**建议申报要素**，每个值注明来源，缺失/冲突注明具体问题；原申报要素保持。多个候选模板不同要分列，不混成一条确定文本。仅在明确人工确认及授权回填时才写回原业务列，并保留修改前值。
5. 退税核查是“真实商品 → 待审HS/适用退税商品代码 → 对应日期及条件的官方退税政策 → 原表退税率”的链条。**图片不能直接证明税率，海关税则税率也不等于出口退税率。**用税务/财政官方文件及适用文库核对；区分关税、增值税与出口退税率。编码、日期、方向、条件或官方数据不足时写“退税率待核”，不填猜测值，不把待核当0%。
6. 对不匹配或置信度不高项，按 [审核证据规则](references/review-evidence.md) 连接海关官方税则、归类法条及相关监管依据。实际涉及两用物项线索时核实清单条目、技术门槛、目的地、最终用户/用途及有效公告；未命中关键词或同HS不能证明不受控，不靠改名规避。
7. `专家审核结论`逐项说明事实/冲突、所据条款及适用条件、为何降低置信度、需补什么。来源未取得或规则年度未核要如实写“待核”；不能编造条号，也不能给每件普通商品硬套一条军民两用法条。
8. 专家审核置信度单独分高/中/低，与预审等级、监管状态、人工审核状态分别记录。要素不完整、退税未核或关键管制条件未排除时，整体专家结论不能为高；分项确定性可另记。资料不足与系统查询失败分开标识，失败项不视为已审核。
9. 专家决定通过或退回；可直接修改待审编码后通过，改码前后值、原因、操作者和时间必须留痕。退回必须选择对象角色、具体责任人（能确定时）及问题清单：可退回业务员处理商品关系/编码分歧，或供应商补事实、要素和图片；其他责任方仅在业务明确时增加，不擅定审批路径。AI可给建议对象，不能自动派发。
10. 任何补料重传都整表重新预审：不区分未变商品，也不能仅因只改要素/税务证据就认定不影响归类；业务员重新确认并提交后，专家对新版本重新审核。行级影响判断和预审复用留作后续优化。所有结论绑定版本；旧专家通过不自动沿用到新版本。

## 四、置信度与Excel标记

| 等级 | 预审归类 | 专家审核 |
|---|---|---|
| 高 | 关联清楚、关键事实充分一致、当期官方依据支持唯一编码；不是“编码相同”或“命中历史”就评高 | 待审编码及当期依据明确，要素、可验证图片信息、退税依据和相关监管条件均核清，无关键未决项 |
| 中 | 大类和候选依据明确，但细分参数或来源版本待核 | 身份及主要归类较明确，存在可列明的要素/税务或非关键佐证缺口，需补指定资料 |
| 低 | 身份/关联不清，资料关键冲突或跨税目分支无法排除 | 关键要素与图/资料冲突、归类无法确定，或关键监管/税务适用条件不足以支持结论 |

- 信息越完整、有效、可信且一致，置信度越高；不按图片数量、文本长度机械加分，不设百分比分数。缺非必要图片或选填项不单独判低。
- `预审结论`标记不一致、无法确认、空缺及异常原因；有实质冲突/低置信度红字浅红底，待核/中置信度黄底。比较状态与置信度独立：高置信度也可能与供应商不一致。
- 专家`置信度`同格写`等级｜依据：…｜待补/修改：…`；低红字浅红底、中黄底。`专家审核结论`承接完整的逐项核对与法规说明。
- 原申报要素中待填写/冲突片段及新增建议要素对应片段标红，原文本不被占位或建议覆盖；空白格的补料占位放建议要素/问题列。优先富文本局部标红；无法实现时整格红字并在明细区分已填与待填。
- 导出前核验：全部装箱商品可追溯、主名与别名分明、原值保留、两新增HS相关列顺序正确、图片真实读取、两阶段不混淆、异常有原因、退回有对象及问题、公式/图片/合并/其他页签保真。不能保真时明确具体限制，不声称已完成原模板回填。
