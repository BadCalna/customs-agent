# 两页签联合识别：HS归类与申报要素回填

仅关注“装箱明细”和“申报要素”两个页签。先用装箱明细的合同第一条品名与附件清单品名共同确认商品品名，用规格与厂家提供型号共同构成规格型号信息，再稽核申报要素页的对应商品。结合品名、规格型号、真实图片查询归类及申报要求，利用两页签已有信息填写申报要素，说明置信度和待补资料。

箱件汇总及其他页签随原工作簿保留，不作为本次分析输入或必需条件。流程止于供应商补充、业务定稿和物流审核。

## 输入与交付

- 输入为实际业务Excel，可附铭牌、图片、规格书和材质证明。先读 [references/business-template.md](references/business-template.md) 定位两页签字段及回填位置；页签可带“节点①”等前缀，按表头语义识别，不固定行号。
- 交付保留原模板的独立`.xlsx`工作副本，在“申报要素”页填写可证实的数据，新增或使用“置信度”列，并保留原始值及修改依据。原文件不覆盖；输出标识“AI辅助填写，待人工审核”。
- 装箱明细中的每条商品都须有处理结果；分箱不重复归类，不因现有申报页遗漏而跳过。不确定或查询失败必须如实说明，实际验证不使用模拟结果替代联网核查。

## 一、从两页签确认商品及关联

1. 识别两页签的数据区、表头、合计、备注、公式与合并单元格。缺页签时说明哪些判断受限，继续处理已取得资料；不索要或读取箱件汇总补足本轮范围。
2. **品名**：同时读取装箱明细“合同第一条品名”和“附件清单品名”。相同则合并识别；一项更具体且相容时吸收具体描述；实质矛盾时保留两个原值，标明疑点并提问。不能只取其中一列，也不把二者机械拼接成新申报名称。
3. **规格型号**：同时读取“规格”和“厂家提供型号”，记录为“规格：…；厂家型号：…”。去重但保留互补参数及来源；型号、功率、尺寸、材质冲突时分别列出，不静默选择一个值。厂家型号列的10位数字或无关单位需检查疑似错列，不能当成已确定型号/HS。
4. **申报页匹配**：先以合同号＋合同项号定位，结合两种品名、规格型号及物料代码核对是不是同一商品。品名是语义稽核重点，不能仅因同名就跨合同串联；同合同项关键属性不同时保留子记录。
5. 申报页合并多个合同项时建立明确成员关系。项号不清或品名不符时标“匹配待确认”，保留可能关系，不能把候选资料写入错误商品。数量、单位可辅助校验关联，不主导归类。
6. 读取匹配申报行的品名、附图、原海关编码和原申报要素，比较原申报品名与装箱品名；已有HS、“OK”“已修改”仅为待核输入，不是归类正确或适用当期的证明。
7. **图片**：读取真实嵌入图、浮动图或附件；WPS `DISPIMG`须解析图片ID、关系和媒体。读取不到时明确“图片未能读取”，不能把公式/文件名当作已识别图片。同一申报行含多个型号时确认图片适用范围。
8. 图片只证明可见结构、标识和铭牌文字；不能从外观猜成分、工艺、功能或性能。已有品牌信息作为身份核实及要素填值的辅助证据，不从生产商名称推定品牌。

每条商品保留原sheet、行号/单元格、合同项和关联申报行，确保后续填值及补料不会错位。

## 二、通过官方与第三方核查归类

主查询输入为：已确认的商品品名＋联合规格型号＋真实图片。先定位类别，再按材质、结构、功能、用途、工艺和技术参数排除分支，不仅按相似名称、品牌、旧HS或退税率选码。

官方优先：

- [海关商品编码表](https://online.customs.gov.cn/ociswebserver/pages/cus/#/tgcs/info?paramCode=CusComplex)
- [海关商品申报要素表](https://online.customs.gov.cn/ociswebserver/pages/cus/#/tgcs/info?paramCode=CusMerchElement)
- [海关监管证件代码表](https://online.customs.gov.cn/ociswebserver/pages/cus/#/tgcs/info?paramCode=CusLicensedocu)

第三方补充：[hsbianma.com](https://www.hsbianma.com/)。按品名搜索后打开候选编码详情，核对商品描述、细分条件、要素与更新时间。第三方、企业历史和原表资料是参考，不能标作官方核准结论。

- 核对拟申报日期、进出口方向及适用税则、归类规则、章注/类注；未提供日期时按查询日初判并注明正式适用日期待核。
- 每条记录具体来源URL、查询日期、规则版本/生效日期，区分三者。官方未声明年度则“版本待核”，不推定当年有效。来源冲突保留差异，未解前不出高置信度。
- 同类别可复用已核且有效的查询；遇登录、验证码或访问限制不绕过。查询失败、资料缺失与资料矛盾分别说明。
- 按真实商品选择4位税目、6位HS或10位中国商品编号；在正式海关编码列只填有依据的完整编号，按文本保存，不补零拼码。13位CIQ不得混入10位商品编号。
- 每条给出已知事实、支持的分类条件、未排除的分支。无法确定唯一编号时写“待补资料，暂不定码”，将条件候选另列；不同候选的适用条件分别解释，不让用户任意选。

## 三、匹配官方要素并利用两页签信息回填

1. 找到对应编码的官方要素模板。官方以不同长度前缀给模板时，采用“编码以该前缀开头”的最长匹配，不统一截前4位。保留官方字段名、顺序和可取得的必填标识。
2. 从装箱明细的两种品名、规格、厂家型号、其他明确字段，以及申报页原要素、图片可见信息等提取值。逐项记录“已填、部分已填、待补、冲突”及来源，能核实的就填入工作副本的申报要素。
3. 对原有要素逐项稽核，不把“已有文字”等同于“正确完整”。品牌、型号、材质、功率、用途等矛盾时列明双方来源；该字段标“待确认”，保留原值，不自动沿用任一方。
4. 不由304/316L补成分百分比，不将DN当实际外径，不从品牌推断品牌类型或享惠情况；不编造“无牌”“不享惠”、GTIN、CAS、用途或材料。
5. 缺失必填值用明确占位，如“用途：待补充（请说明设备及具体作用）”；部分值与冲突值同样标出待填部分或待确认问题。选填项未提供可留空并注明选填，不自动变成必补问题。
6. 未取得正式模板时写“官方申报要素清单待核”，可整理已知属性及归类提问，但不编造官方必填总数、字段顺序或完整性比例。多个候选模板不同时分列适用要素，不混成一条确定申报文本。
7. 每个待补项说明“缺什么/何处冲突、为什么影响归类或要素、供应商需回答什么/提供什么证据”。补料后重新判断受影响的商品和要素。

用户已授权在**输出工作副本**回填HS及申报要素，无须再次要求许可。编号有依据、商品匹配清楚时写入海关编码列，已知真实要素写入申报要素列；原值、来源及AI建议身份在核查记录保留。待确认HS不写成唯一确定编号，品名实质不符时保留原品名并列明建议及原因，供物流确认。

## 四、置信度：高、中、低，原因与补数写在同一列

**有效、相关、可信且一致的信息越完整，置信度越高**；不按文字长短、重复行数、图片张数或字段数量机械加分。新增资料若矛盾或无关，不提高等级。缺非必要图片、选填项、包装重量不单独降级，关键身份/参数缺失则明确降级。

| 等级 | 判断标准 |
|---|---|
| 高 | 商品匹配清楚；品名、规格型号及必要佐证明确关键属性；适用日期官方依据支持唯一归类；必填要素完整，无未解决矛盾 |
| 中 | 商品及主要类别较明确，候选有依据，但细分参数、部分要素或官方版本尚待核实；补充指定信息后可进一步确认 |
| 低 | 商品身份不清、关键资料明显冲突、关键结构/工艺缺失导致跨税目分支无法排除，或缺可靠归类依据，不能确定怎么归类 |

- “置信度”单元格必须包含**等级＋判断依据＋需要补充的信息**；无法归类时特别写明分歧在哪里。不得只写“低/信息不足”，也不能只把原因放在其他列。
- 推荐格式：`低｜依据：…｜待补充：…`。例如：`低｜依据：品名为旋转磨头，装箱写钨钢，申报写合金钢；材料及结构不足以确定分类｜待补充：具体成分、是否有切削刃、实物图及用途。`
- 高也说明依据，待补信息写“无，仍待物流审核”；中说明尚缺哪些参数/必填项。可另列详细归类理由，但不能取代同格说明。
- 仅有第三方/历史资料、官方适用版本未核时不评高。缺字段不一律评低，已知信息足以确定大类但缺细项通常评中；查询执行失败另记“分析异常”，不伪装成货物错误。
- 不预设各等级数量，不编造置信度百分比。人工审核状态及监管状态与置信度分开记录。

## 五、输出位置及红色标记

1. **申报要素页**：按表头定位品名、海关编码、申报要素和置信度。海关编码/要素写入工作副本相应字段；置信度列不存在时追加到现有使用列之后，不占用无表头但已有审核意见的列。
2. **待填写的申报要素标红**：缺失、部分缺失或冲突待确认的字段名及占位/问题使用红色字体（如`#FF0000`）。同一格含已填和待填内容时优先用富文本只标红待填片段；无法保留富文本则整格红字，并另附逐项明细区分已填与待填，注明展示方式。
3. **低置信度标红**：整个置信度单元格的等级、依据、待补信息均用红色字体，可加浅红底。中置信度沿用黄底，高保持正常；不能只在另一张统计页标红，也不以整行红色代替具体缺项标记。
4. 可新增“AI核查明细”承接合同商品关系、原品名/规格/型号、原HS及原要素、建议与来源、逐要素状态和红色缺项。该明细辅助说明，不能代替业务页实际回填及置信度说明。
5. 只在装箱明细有记录、申报页未找到的商品列为“申报页待新增”；字段与关联充分时可在副本追加待审条目并保持合计公式范围正确，关联不清时留在核查明细待确认，不能填进相似名称行。
6. 同一申报行包含多个规格时保留成员及型号差异；需要不同编码或不能共用要素时提出拆分建议，不把不同要素合并为一个虚假的确定值。单位、数量、金额不因归类重写。

导出复核：全部装箱商品可追溯；两种品名与两类规格来源均纳入；图片已读/未读如实记录；编码与模板对应；可填值已填；待填要素红字、低置信度红字、中黄底正确；置信度同格有依据和具体补料要求。保留原工作簿其他页签、公式、图片及合并单元格，原件不覆盖。工具无法保真时明确交付限制并提供独立填写结果，不声称完成原模板回填。

## 六、监管与资料版本

- 保留既有监管辅助核查：按真实技术参数核对[商务部出口管制清单及公告](https://exportcontrol.mofcom.gov.cn/ckgzqdsjk.shtml?columnID=9&num=1)，记录依据、适用条件及缺失资料。关键词、同HS、供应商声明或改名不能单独证明不受控。
- 原品名及有依据的规范名建议分开记录；不能通过删敏感词或模糊名称规避管制。既有名称建议变化仍标黄，“名称是否替换”放在核查明细末列供人工确认。
- 每次按拟申报日期核对有效规则；规则或资料变化重查受影响商品，保留旧结果与来源。本Skill不自行启动定时任务或写业务数据库。
