# 独立验收｜事先固定的评分矩阵

对照：`f66c8fa851fedece88d0e154528b8084c13f089b` 与集成后的工作树；生产入口 `/`。每项满足全部条件得 5，否则得 0；每类 20，共 100。未测记 U、不折算；保留失败测量。分数衡量以下场景，不代表安全审计、WCAG 认证、审美投票、真实性能或真人效率提升。由未改产品的 audit 评定。

| 维度 | 编号、可重跑的判定条件（每项 5） |
|---|---|
| 登录与视觉入口 A | A1 未登录能看见产品身份、具标签的账号密码与登录按钮而看不见任务；A2 未登录页除身份和表单外说明具体工作流程/价值（至少两步活动）；A3 错密得到可见反馈，改正后无需刷新进入工作台；A4 可见退出后工作区与任务消失，刷新仍为登录态入口。 |
| 主题与显示偏好 B | B1 用户无需操作系统设置即可切换至少两种实质不同配色；B2 切换后刷新仍保留选择；B3 登录与登录后同样保留并呈现所选配色；B4 至少三种不同配色可由可见且有可访问名称的控件逐一选择，分别截图并检查背景/前景有实际变化。 |
| 队列与定位 C | C1 业务员点选有权限任务后看见正确标题及当前版本；C2 按标题关键词缩窄列表，清空恢复；C3 按阶段过滤缩窄且重置恢复；C4 不匹配搜索能与「没有任何任务」区分，且能直接恢复列表。 |
| 数据与溯源 D | D1 当前版本有运行总数、成功/失败数且与实际 run API 对齐；D2 一个汇总视图呈现至少两种带计数的商品/审核结果分类，不混为审批决定；D3 可从当前页打开商品看到来源行或页签，且能明确识别模拟结果不可用作审核依据；D4 切换 V2→V1 后汇总/明细分母分别随实际 8→2 条切换，无旧版本残留。 |
| 响应式与交互 E | E1 1440×900 登录和已选任务页面无文档级横向溢出（≤1 CSS px）；E2 390×844 同条件无文档级横向溢出；E3 手机首屏任务打开后可触控到达版本和数据，桌面、手机均成功打开商品；E4 键盘可从账号经密码提交登录，且浏览器未抛未捕获 JS 异常。 |
