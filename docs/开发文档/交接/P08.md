### 主控接入

页面引入 `web/styles/tasks.css`，通过现有统一client挂载。下例中的 `mountSelectedTask` 和 `openItemCard` 为宿主页面自己的接线函数：

```js
import {createTaskList} from "./components/task-list.js";
import {createRunProgress} from "./components/run-progress.js";

const progress = createRunProgress(progressHost, {
  client,
  onSelectItem: openItemCard,
  // 默认不提供onRetry，retryAllowed默认false；待P13及正式授权能力发布。
});
const tasks = createTaskList(taskHost, {
  client, pageSize: 10,
  onSelectTask: mountSelectedTask,
});
await tasks.load();

// 每次切任务、版本或执行记录，都必须重新调用；没有run也要清旧结果。
await progress.open({
  taskId: task.task_id,
  versionId: selectedVersion.version_id,
  runId: selectedRun?.run_id || null,
  versionNumber: selectedVersion.number,
  isVersionCurrent: selectedVersion.version_id === task.current_version_id,
});

// 页面卸载、登出或切换登录身份时销毁两者，重新登录后重新挂载。
tasks.destroy();
progress.destroy();
```

- 列表调用 `client.listTasks({stage,limit,cursor})`，选中后调用 `client.getTask(taskId)`；回调返回完整TaskDetail。关键词只筛本页，不冒充全库供应商查询。
- 运行组件调用 `client.getRun(runId)`，验证任务/版本/执行三重身份。只有当前文件版本且 `run.is_current` 为真、执行状态为queued/running时继续轮询；请求返回后再安排下一次，不并行堆积。
- `run.is_current` 表示该版本/阶段的有效执行，不代表文件版本仍是当前版本。同版本可同时有precheck和expert_check记录，不能随意取首个is_current；当前任务首先采用 `task.latest_run_id`，历史版本由宿主明确选对应执行。
- 每次open/destroy取消后续计时器，并使已发出请求的结果失效；公共client未提供AbortSignal，因此没有声称中断已在传输的网络请求。V1晚响应、晚错误、晚重试结果均不能回写V2。
- 轮询失败显示错误并保留上次结果、标记暂停；“重新连接”恢复读取。空数据、403、404和501分别呈现，不把错误渲染成成功空页。
- 完成率严格采用服务端汇总，校验非负整数、分类合计、重复行和明细计数；已结束=成功+技术失败。100%不表示业务审核通过。业务待补与技术失败分开。
- `onSelectItem` 返回 `{task_id, version_id, run_id, item_id}`，由宿主接到P07/P11卡片。前端不据此绕过服务端对象权限。

### P13重试接线约定

当前公共client只发布读取方法，写接口尚未就绪；P08只发回调意图，不自行fetch、不增加HTTP端点。接通时由宿主注入集中写适配器和**正式服务端授权结果**，不能凭角色、确认写权限或预览配置推断可重试。契约目前没有retry权限枚举，需主控/P13先明确能力发布方式；没有时保持默认关闭。

```js
const progress = createRunProgress(progressHost, {
  client,
  retryAllowed: authorizedByPublishedCapability,
  async onRetry(intent) {
    // intent: {task_id, version_id, run_id, item_ids, idempotency_key}
    // 集中适配器按P13正式契约发出请求；idempotency_key送Idempotency-Key。
    const result = await retryAdapter(intent);
    return {run_id: result.run_id, task_id: result.task_id, version_id: result.version_id};
  },
});
```

只允许当前版本已返回的failed行；去重、单次提交锁定。相同选择失败后重试复用同一UUID幂等键，改变选择/上下文则换键；409/501等错误保留选择并展示原因。成功必须返回同版本**新run_id**，组件从服务端读取新执行，保留旧成功行和原失败记录。历史执行、正在执行、轮询出错、未授权或后台未接通时不发送重试。服务端仍须校验权限、当前版本与幂等性。
