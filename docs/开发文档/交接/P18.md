## 1. 交付文件清单

### A. 专家 AI 核查组合引擎与提示词
- `adapters/engines/expert_check.py`：
  - 定义 `ExpertCheckEngine`（`engine_version="expert-check-0.1.0"`、`prompt_version="expert-check-json-1"`、`rules_version="d4-0.6-p14-p17-p18"`），组合 P14 `DeclarationElementsSource`（及可选 `HsLookupSource`）、附图 `ImageFact` / `payload.evidence`、P17 `TaxRateSource` / `RegulatorySource`、可选 P15 `HistorySearchSource`（默认 `None`，仅作参考不作结论）与可选多模态判定模型。
  - 提供构造期自检结构 `AspectEvaluation` 与 `ExpertCheckAssembly`，在返回前强校验 12 条口径红线；`expert_check()` 捕获内部 `ValidationError` / 异常并结构化降级为 `evidence_status=query_failed`（`EXPERT_CHECK_SELF_CHECK_FAILED` / `EXPERT_CHECK_INTERNAL_ERROR`）及四项 `unknown`，绝不抛 500。
- `adapters/engines/prompts/expert/system_prompt.txt` & `adapters/engines/prompts/expert/README.md`：
  - 声明严格的 JSON 输出结构（`ModelExpertJudgment`）、不可信输入锚定风险提示、禁止审批/退回/置信概率词汇。

### B. Mock 固定核查场景
- `adapters/engines/mock.py`：
  - 保留原有 `expert_conflict` 场景与 `tech_failure` 异常路径（供 inline runner 回退校验）。
  - 新增四个固定分项 `unknown` 场景：`expert_elements_unknown`、`expert_images_unknown`、`expert_tax_unknown`、`expert_regulatory_unknown`（各自仅将目标分项标为 `unknown` 且不挂虚构证据，其余三项标 `matched` 并附 `mock-obtained` 可定位证据）。

### C. 纯渲染分项核查组件
- `web/components/expert-checks.js`：
  - 导出 `EXPERT_ASPECTS`、`EXPERT_VERDICTS` 与 `renderExpertChecks(el, options)`。
  - 只消费 `ExpertCheckRef`（`run_id`、`submission_id`、`target_hs`、`findings`）及可选 run 明细证据索引、当前 `submittedHs` / `expertFinalHs`；按固定四行顺序（申报要素 / 附图 / 退税率 / 监管条件）展示 `verdict` 徽章、中文理由、证据条数及 `<details>` 可展开定位详情；缺失分项一律按 `unknown` 合成展示。
  - 严格纯渲染：不发网络请求、不读写存储、不出现“通过 / 批准 / 放行 / 已核实”字样；全量 HTML 转义并在重渲染时卸载旧事件监听。

### D. 离线评估体系与测试
- `evaluation/expert/`（`__init__.py`, `__main__.py`, `cases.py`, `runner.py`, `settings.py`, `README.md`, `report.json`）：
  - 实现 18 条合成技术样本测试集（72 次分项判断）、四分项与总体 `3x3` 混淆矩阵、`unknown` 覆盖率、`false_matched_on_unknown`、`conflict` 召回率、失败样本明细及 SHA-256 可复现校验。
  - 实现 `ExpertGoldSuite` 契约：拒绝将 `synthetic=true` 样本或缺少标注人/时间的输入当作金标准，技术样本报告固定标定 `threshold_verdict.status = "pending_expert_gold_standard"`。
- `tests/p18/`（`test_expert_check.py`, `test_expert_mock_scenarios.py`, `test_expert_trigger_consistency.py`, `test_expert_evaluation.py`, `test_expert_dependencies.py`, `test_expert_components.py`, `expert_checks.test.mjs`）。
- 文档更新：`docs/开发文档/Agent输入输出与证据约定.md`（D4 §2 & §9）、`docs/开发文档/阶段0/验收用例与记录.md`（D5）。
