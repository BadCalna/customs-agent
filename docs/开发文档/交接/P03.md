再运行以下只读检查，确认样本与本轮基线相符。当前本机只有一个 xlsx，基线 SHA-256 为 `f68c5094cd11835cc1118627db58785715fc5e5c0f7ba43f2b87578616959156`。

```sh
.venv-customs/bin/python - <<'PY'
from pathlib import Path
from hashlib import sha256
from zipfile import ZipFile

samples = list(Path("docs/参考模板").glob("*.xlsx"))
if len(samples) != 1:
    raise SystemExit("请在 P03 回交中明确本轮输入样本，当前匹配数量并非 1。")
sample = samples[0]
print("SHA-256", sha256(sample.read_bytes()).hexdigest())
with ZipFile(sample) as workbook:
    assert workbook.testzip() is None
    assert "xl/workbook.xml" in workbook.namelist()
print("样本 ZIP 结构可读")
PY
```

首次实现可直接用 Python 标准库的 `zipfile`、`xml.etree.ElementTree` 和 `hashlib` 检查结构。若试验需要 openpyxl 等额外依赖，在 `experiments/excel_fidelity/` 管理独立环境与依赖文件，并回交完整安装和运行命令。先保存基线摘要与原件哈希，再在 `data/private/p03/` 生成试验副本。
