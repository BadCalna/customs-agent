## 范围与实现

- 分支 `feature/P20-exports`，起点 `e986a9a`；不合 main，不混入 P08 差异。
- 仅改本包两个导出模块、独立 API、`tests/p20/` 和两份文档。没有模型、迁移、公共 schema、权限、全局路由或依赖变更。
- 使用 P04 申报商品源位置，不重复装箱成员/项号校验；用户已明确本轮不处理 P04 编号问题。
- 用户确认清单八列：**合同号、项号、品名、原位置、问题、需补充信息、建议处理人、反馈**。

| 文件 | 行为 |
|---|---|
| `adapters/files/export_workbook.py` | 明确 task/version/run/原件摘要，适用时 submission/decision；语义复用 AI 推荐/预审结论列；缺列走 P03 保真插列/补结论；逐部件、单元格、样式和媒体审计 |
| `adapters/files/export_issues.py` | 标准 XLSX 八列清单，项号文本保留、筛选/冻结/换行、黄色反馈栏；来源写文档属性，不写系统商品 ID |
| `apps/reviews/api/exports.py` | 独立 router：`POST /versions/{version_id}/exports`；对象权限及业务员/专家角色检查；版本/执行/提交/决定绑定；直接返回附件及 no-store/mode/run 标记 |
| `tests/p20/` | 27 项模块/API 合成测试 |

## 模板和结果规则

- 保留供应商原 HS/要素、人工确认、专家置信度、历史意见、其他页签、公式和原始媒体。第一份实际布局 AF/AG，另两份 M/AE，仅是样本观察，代码不硬编码。
- 上游明确给高/中/低时低红、中黄，待补文字红；只有数值时显示“等级未提供”，不定义阈值。预审结论不写专家置信度列。
- 缺推荐留空；技术失败清空本次推荐格并说明原因，不拿旧码冒充成功。
- mock 文件名和每条预审结论醒目标测试。模式取持久化结果；缺来源保守 mock，不因当前引擎切换而变成 live。
- 查询失败只导出已有问题，不推造供应商补料；空清单不表示人工批准。导出不退回、不通知、不提交、不填拟申报日期。
- 所有字符串作为文本；前导零保留，等号开头不执行，超长/非法字符拒绝而不截断。
- 宏/签名、受保护页、重名结果列、结果格公式/合并、缺 AI 但已有其他结果列等不支持状态拒绝；动态/条件图片沿用 P03 支持限制。
