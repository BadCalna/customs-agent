### 组件用法与事件

组件都是纯渲染函数：接收数据与回调，不自己发请求，不写 `localStorage`/`sessionStorage`，
不修改业务状态。事件只回调页面，由页面决定是否调用 `web/state.js` 或 `web/api.js`。

```js
import { renderCommodityList } from "/demo/assets/components/commodity-list.js";
import { renderCommodityCard } from "/demo/assets/components/commodity-card.js";
import { renderHsComparison } from "/demo/assets/components/hs-comparison.js";

renderCommodityList(listEl, {
  items,                 // ItemListEntry[]；也兼容直接传 ItemCard
  selectedItemId,        // string | null，行选中态
  annotations,           // 可选 Map/对象：{itemId: {label, note}}，仅演示页场景标签
  onSelectItem(itemId, item) {},
  onEscape() {},
  ariaLabel: "商品列表",
});

renderCommodityCard(cardEl, {
  card,                  // ItemCard | null
  onSelectSource({ stageKey, label, sourceId, sourceKind, text, trigger }) {},
  onSelectImage(image) {},
  onOpenRun(runId) {},
  contractNotes: false,  // 演示页为 true，显示契约缺口说明
});

// 也可单独挂阶段对照块
renderHsComparison(comparisonEl, { card, onSelectSource });
```

事件与键盘：

| 交互 | 行为 |
|---|---|
| 点列表行 / Enter / Space | 调用 `onSelectItem(itemId, item)`；页面更新选中态并重渲染卡片 |
| `↑` / `↓` | 在列表行之间移动焦点；不改变选中项 |
| 列表内 `Esc` | 调用 `onEscape()`；P07 页清除选中并保持列表焦点 |
| 卡片阶段来源 `↳` 按钮 | 调用 `onSelectSource(...)`；P07 页展示完整 `source_id` 与来源类型 |
| 卡片附图条目 | 调用 `onSelectImage(image)`；P07 页展示状态、源单元格、错误原因、`download_url` |
| 卡片执行引用 | 调用 `onOpenRun(runId)`；P07 页只展示引用，不请求执行详情 |
| 卡片来源面板 / 页面 `Esc` | 关闭来源面板；再按一次清除选中 |

展示口径：

- 五阶段为预审建议、业务员确认、提交值、专家建议、专家终值；供应商原码来自
  `facts.supplier_hs_raw`，空白原样显示，不用任何建议值补位。
- 阶段值 `null` 且有 `source_id` 显示“未给出建议”，并注明“有来源引用但未给出值”；
  值与来源都为空显示“—”。
- `result_mode=mock` 在卡片顶部黄条、卡片徽章与列表行徽章三处可见。
- `task_stage` / `submission_status` 只显示字段原值，不翻译成审批结论。
- 六类比较结论全部有独立标签与 tone；`comparison_status=null` 显示“未得出结论”，
  仅根据 `latest_run_id` 是否为空区分“未执行”，不推断技术失败或业务结论。
- 专家改码并列原提交码与专家终值；说明 `latest_expert_check.target_hs` 是原提交码，
  并明确新终值不在该次核查记录内、页面不推断已核查。
- 图片 `read_failed` 与 `absent` 分别文案；`read_failed` 保留错误信息与源单元格；
  多图使用可滚动网格，单图状态与整体 `image_status` 同时展示。
