## 功能

- 现有调试台新增“专家核查”，保留独立预审默认行为。
- 输入待核查 HS、供应商退税率原文、贸易方向、可选退税代码及用户给定的日期/税则版本。固定样例和父运行不能被覆盖阶段或核查编码。
- `apps/agent_debug/expert.py` 复用 P18 `ExpertCheckEngine`，显式注入同一固定版本的 HS、要素、退税来源；可选消费同 release 的 `p17_regulatory`，不把监管代码台账当监管条件。
- 展示要素、图片、退税、监管四项 `matched/conflict/unknown` 与证据。第一版无图；无来源或未经复核时保持待核，不猜日期、不补 8 位码、不替人批准。
- 复用既有单次 transport、连接/凭据管理、权限、外发审批、输入加密、worker、租约、额度及清理。P18 无需语义模型时完成来源核对，模型出站为零；真实模型错误不会被引擎降级后冒充执行成功，不自动重发。
- 来源证据以哈希标识精确关联到分项。当前 C 映射只支持 HS/注释，未支持类别不造链接；相同定位的要素记录不能误链到 HS。
- 运行详情、列表筛选、复制重跑支持阶段。MOCK 明确显示为合成模拟。专家结果始终待人工复核，仅写调试记录，不修改正式任务、提交、确认或决定。

无需新增依赖、数据库模型或迁移。现有部署注册和 live 开关继续按原方式配置；本次不打开生产 live。
