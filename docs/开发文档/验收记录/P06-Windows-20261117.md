## 建议用户先验证

1. supplier_a 登录，打开已导入的多合同任务，核对 25 条商品与图片；点行可展开原文及来源。
2. 上传一份待填 Excel，观察来源、品名、供应商原 HS 和解析问题是否符合原件。
3. 同一任务补料重传：选择“当前任务补料，新增版本”，检查 V1/V2 原件和数据独立保留；同文件重传有重复确认。
4. 退出后以 operator_a 登录，从待认领池认领多合同任务，确认认领后能查看商品。
5. 再换 operator_b，确认不能查看已经被 operator_a 认领的任务。
