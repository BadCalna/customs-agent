# 开发入口

更新于 2026-11-14。P00 工程已可本地运行，见 [运行说明](运行与交接说明.md)。P01 可开工，P03 可以按[派工单](交接/P03.md)并行执行。

优先级：Jay 最新明确决定 → D1 业务规则 → D2 数据约定 → 本轮开发计划及 D3/D4 → 旧原型和旧技术方案。发现冲突时记录并修正文档，不自行恢复旧规则。D3/D4 当前为 v0.1 设计契约；P02 验证并发布契约版本后，才作为执行 Agent 的稳定输入。

开始执行时先派发 **P00 工程启动**。P00 可与 **P03 模板保真验证** 并行；P01、P02 完成后可派发页面任务 P07/P08/P11。不要让多个 Agent 同时初始化工程、重写公共模型或维护同一份迁移。

旧的 51 项 A01～L04 工程任务仍用于范围追踪，已全部映射到本轮 23 个任务包。旧任务图的人员工时及执行顺序不再用于本轮排期。
